A top-down stealth game: reach the green exit unseen by the five patrols. They patrol back and forth with vision cones and give chase when they see you; hold C to crouch and move slower. Enter starts on the title screen, Esc pauses.

## Run it

```sh
node main.ts
```

Serve the repository root with any static server and open `game/index.html` in a desktop browser; it plays from the static files in `game/` with no network request.
